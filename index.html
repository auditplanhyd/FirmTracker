🔥 Firebase Setup

📋 Step 1 — Create Firebase Project
  1. Go to console.firebase.google.com → Add project → name CA Tracker → Create
  2. Click </> Web → register app → copy the firebaseConfig object shown
📦 Step 2 — Enable Firestore + Anonymous Auth
  1. Firestore Database → Create database → Production mode → Done
  2. Firestore → Rules tab → replace with:
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if request.auth != null; } } } Click Publish.
  3. Authentication → Get started → Anonymous sign-in → Enable → Save
🚀 Step 3 — Host on GitHub Pages (unchanged)
Upload index.html to your repo → Settings → Pages → main branch → Save
